# Unespacio · Plataforma Web

Copia independiente de la interfaz TypeScript de Unespacio Aula, con identidad visual propia para **Unespacio**. El repositorio académico original no se modifica.

## Demostración pública

La vista en GitHub Pages, cuando se active el despliegue desde GitHub Actions, estará en:

https://juanjogamero.github.io/unespacio-plataforma-web/

**Solo demostración con datos ficticios.** Los perfiles de desarrollo y los datos del navegador no son autenticación ni base de datos reales. No introducir datos personales reales, especialmente de menores.

## Identidad

- Nombre de marca: **Unespacio**
- Repositorio: **unespacio-plataforma-web**
- Tipografía: Manrope para encabezados y DM Sans para contenido
- Paleta: verde petróleo `#163D3B`, salvia `#91C4A5`, acento cálido `#D5AE99`, fondo `#F5F8F5`
- Estilos específicos: `src/brand.css`, cargado después de los estilos históricos
- Favicon: `public/favicon.svg`

## Desarrollo

Se requiere Node.js 20 o posterior. Scripts disponibles en `package.json`: `dev`, `check`, `pages:build`.

## Estado

Esta copia conserva las funcionalidades existentes de la aplicación educativa como **punto de partida técnico y visual**. El alcance definitivo del nuevo producto todavía no se ha establecido; no deben considerarse aprobadas todas las funcionalidades heredadas. No hay backend real habilitado.

Los documentos de `docs/producto` son **referencias históricas de Unespacio Aula**, no especificaciones aprobadas para esta nueva plataforma.
